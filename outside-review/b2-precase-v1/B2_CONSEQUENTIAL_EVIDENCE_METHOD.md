# B2 consequential-evidence method

**State:** `FROZEN_PRE_CASE`

The protected question is: did WHU miss evidence that would materially change or qualify the bounded
synthesis? Acquisition may not self-label its misses as non-consequential.

## Anchor order

Before WHU output is visible, evaluation uses the strongest available anchor in this order:

1. decision-driving/pivotal studies or authorities explicitly identified by the professional reference;
2. leave-one-out, sensitivity, certainty, recommendation, or evidence-table analysis already reported
   by that reference;
3. prospectively necessary evidence classes whose absence blocks the bounded conclusion;
4. a deterministic synthesis comparison using the reference's published rule and common inputs; then
5. only if none resolves the question, a later separately authorized qualified-human adjudication under
   frozen qualifications, blinding, conflict, disagreement, and uncertainty rules.

The evaluator records whether each label concerns direction, magnitude, certainty, applicability,
safety, correction status, or an important qualification. A source may be consequential without
reversing direction. Dependence on other sources is preserved.

If no independent anchor resolves consequentiality, the result is `CONSEQUENTIALITY_UNRESOLVED`, not a
machine score or presumed non-consequential miss. That unresolved state prevents the demonstrated
disposition when it concerns a plausible decision-critical gap. `DOCUMENT_RECALL` and
`CONSEQUENTIAL_EVIDENCE_RECALL` always remain separate.

B2B may compare the reference synthesis with a version omitting the missed object, or adding a validated
WHU-only object, only after B2A is sealed and only when the same synthesis construct and rule can be
reproduced without discretionary post-outcome tuning. Otherwise human need is surfaced precisely after
the run; no human is recruited or contacted now.
