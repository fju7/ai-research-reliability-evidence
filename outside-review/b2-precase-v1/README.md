# B2 pre-case independent-review package v1

**Frozen protocol source:** merged `main` commit `0609259ef16a9d9a35ebaef013de1ab53f776d73`

**Purpose:** a narrow independent methodological review of the frozen B2 Acquisition Adequacy
pre-case design before any case is selected.

What Holds Up (WHU) is intended to produce bounded, source-backed research for sophisticated
nonexperts and generalists. B1 established only that inexpensive-model synthesis was feasible under
favorable, reference-rich conditions. B2 is intended to test acquisition adequacy when WHU starts
from a bounded question rather than a supplied corpus. No B2 case has been selected.

Begin with `INDEPENDENT_REVIEW_PROMPT.md`. The nine copied protocol/governance files are byte-identical
to the files merged through PR #305. `MANIFEST.sha256` fixes the byte identity of every reviewer-facing
file other than itself. The package commit and tree are fixed by the public review PR.

## Contents

- `INDEPENDENT_REVIEW_PROMPT.md` — controlling review instructions.
- `B2_ACQUISITION_ADEQUACY_PROTOCOL.md` — target property, sequence, stopping and B2A/B2B boundary.
- `B2_CASE_SELECTION_CRITERIA.md` — eligibility, contamination and prospective selection procedure.
- `B2_REFERENCE_BACKBONE_REQUIREMENTS.md` — protected-reference quality, updates and WHU-only evidence.
- `B2_LEAKAGE_AND_BLINDING_PLAN.md` — role split, custody, commitments and fail-closed leakage states.
- `B2_SCORING_AND_DISPOSITIONS.md` — found states, equivalence, scorecard and dispositions.
- `B2_CONSEQUENTIAL_EVIDENCE_METHOD.md` — independent anchor order and unresolved state.
- `B2_CONTROL_STACK_COST_ACCOUNTING.md` — cost, labor, intervention and latency accounting.
- `B2_PRECASE_MANIFEST.json` — frozen pre-case identity and source hashes.
- `B1_CLOSEOUT_B2_PRECASE_GOVERNANCE.md` — narrow B1-to-B2 governance context.
- `MANIFEST.sha256` — deterministic reviewer-package hashes.

## Deliberate exclusions

This package contains no B2 case or candidate topic, protected reference identity or corpus, internal
hostile-review register, internal adjudication, preferred fix, hidden score expectation, conversational
history, or prior review finding. It is not a request to reopen B1, redesign WHU generally, run B2,
publish content, or begin engineering.

No acquisition, model, search, paid-human, production, publication, deployment, or subscriber action is
authorized by this package.
