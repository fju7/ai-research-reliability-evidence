# Public Evidence Package Index

The WHU repository and its PR pages are private as of the freeze, so they are not represented as public reviewer links. This directory is the self-contained internal-material package to be transmitted through an authorized review channel. No new public repository or visibility change has been made.

Public external evidence is listed in `REVIEWER_SOURCE_LEDGER.md`. Prefer stable records where available:

- peer-reviewed proceedings or journal pages: EA16, EA23, EA27, EA33;
- public preprint records with version history: EA17–EA22, EA24–EA26, EA29;
- government or public-institute pages: EA13, EA14, EA32;
- independent evaluator pages: EA01–EA04;
- official first-party research pages, which must be labeled as such in the review: EA05–EA12, EA15;
- professional evidence-synthesis standards: EA30, EA31.

The controlling Substack and brief are included as frozen files. The PR #30 design is represented by a neutral summary rather than a private link. The merged PR #79 and PR #88 internal reports are not required to evaluate the controlling claims and are not included because evaluative internal conclusions could anchor the reviewer.
