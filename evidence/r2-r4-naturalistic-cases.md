# R2–R4 naturalistic cases

**Status:** naturalistic, incident-selected, descriptive only. These cases cannot estimate incidence, prevalence, comparative severity, or causal effects.

## R2: nine became eight

A review helper selected changed sentences only when their normalized length exceeded a threshold. Nine sentences had changed; eight reached the reviewer. The returned review was clean for that contracted population. The consequential issue is denominator loss, not a demonstrated error in the eight reviewed judgments. A skeptical reader should treat this as ordinary population-accounting software failure with an assurance consequence.

## R3: unknown became zero

A missing model-price lookup was represented numerically as zero. A spending control could therefore treat an unknown cost as free. The record supports the state-coercion pathway and the possibility of a false pass; it does not establish actual overspend. This is a textbook fail-open/default-value defect in a research-control context.

## R4: corrected record, stale index

A corrected issue representation and a stale generated index coexisted. The public reader could encounter the older derivative after the source record changed. This supports a dependency/invalidation defect, not a claim that the text was permanently wrong or that every delivery path was stale.

The private working repository contains the original operational artifacts. They are not redistributed because they expose unrelated private architecture and context. These bounded descriptions are the maximum public evidence available; readers should discount them accordingly.
